    🎛️ دليل البدء السريع - لوحة التحكم
═══════════════════════════════════════════════════════════

📌 الوصول للوحة التحكم:
   https://zamzamumrah.app/admin.php

🔐 بيانات الدخول:
   اسم المستخدم: admin
   كلمة المرور: zamzam2026

⚠️ مهم: غير كلمة المرور من ملف config.php

═══════════════════════════════════════════════════════════

✅ خطوات تعديل الأسعار:

1. افتح: https://zamzamumrah.app/admin.php
2. سجل الدخول
3. اختر التبويب المناسب (مثلاً: برنامج الزيارة)
4. عدل السعر (اكتب الرقم فقط)
5. اضغط "حفظ جميع التعديلات"
6. افتح الموقع وتحقق من التعديلات

═══════════════════════════════════════════════════════════

📱 ما يمكن تعديله:

✓ أرقام التواصل (واتساب، حجوزات، مقترحات)
✓ البريد الإلكتروني
✓ أسعار جميع الباقات
✓ أسماء الباقات
✓ أوصاف الباقات
✓ عناوين الموقع

═══════════════════════════════════════════════════════════

🔧 الملفات المهمة (لا تحذفها):

✓ admin.php       - لوحة التحكم
✓ config.php      - الإعدادات
✓ data.json       - البيانات
✓ get-data.php    - جلب البيانات
✓ data-loader.js  - تحميل البيانات

═══════════════════════════════════════════════════════════

💡 نصائح:

• اكتب الأسعار بدون "ريال" (مثال: 85)
• اكتب الأرقام بدون + (مثال: 966597964958)
• احفظ دائماً بعد التعديل
• اضغط Ctrl+F5 لتحديث الموقع

═══════════════════════════════════════════════════════════

🆘 مشكلة؟

1. تأكد من الحفظ
2. حدث الصفحة (Ctrl+F5)
3. جرب متصفح آخر
4. تحقق من صلاحيات data.json (666)
